# Сайт-візитка на Flask

Це навчальний проєкт, розроблений в рамках лабораторних робіт з веб-розробки.

## Опис

Проєкт є простим сайтом-візитівкою, що складається з двох сторінок: "Резюме" та "Контакти". Додаток створено з використанням фреймворку Flask та розгорнуто на платформі Render.

## Використані технології

* Python
* Flask
* HTML/CSS
* Bootstrap
